# 03 · 页面规范

> 本文件是页面级契约：**目的、入口、内容、动作、状态、接口、验收**。
> 当前为 M0 初稿；用户对象/登录方式确认后补全。页面 ID 与 `02-ia-and-flows.md` 一致。

- 接口：
- 验收：

## 2. 移动端

### P-M01 首页

- 端：移动
- 优先级：P0
- 目的：一眼看到揭东区核心数据，快速进入镇街或问答。
- 入口：微信小程序启动页。
- 主要内容：
  - 标题/更新时间/数据口径提示。
  - 核心指标卡（≥4 个，如区域面积、常住人口、GDP、镇街数量）。
  - 镇街入口（列表/搜索）。
  - AI 提问入口（输入框/快捷问题）。
  - 最近浏览（P1）。
- 主要动作：点指标卡 → 指标详情；点镇街 → 区域详情；输入问题 → 问答。
- 状态：loading 骨架；empty（无数据时提示“数据准备中”）；error（重试）。
- 接口：`GET /dashboard/overview?period=2025`、`GET /regions?level=town`。
- 验收：首页到任一指标详情 ≤3 次点击；无数据不白屏。
- 备注：不要放需要登录才能看的内容（除非确认）。

### P-M02 区域列表

- 端：移动
- 优先级：P0
- 目的：按层级浏览区域。
- 入口：首页“镇街”/“区域”。
- 主要内容：层级切换（区/镇街/村居）；搜索；列表（名称/关键指标/箭头）。
- 主要动作：切换层级；搜索；进入详情。
- 状态：loading / 列表 / 搜索无结果 / empty / error。
- 接口：`GET /regions?level=&parent_id=&q=`。
- 验收：15 个镇街完整；村居按父级正确；经开区/生态城不显示村居入口或显示“无村居”。

### P-M03 区域详情

- 端：移动
- 优先级：P0
- 目的：看一个区域的简介、特色和指标。
- 入口：区域列表/首页。
- 主要内容：
  - 区域名/层级/父级。
  - 地区简介、地区特色（文本）。
  - 指标卡/列表：仅显示该区域适用且有值的指标；无值显示“暂无数据”。
  - 同指标对比入口（P1）。
- 主要动作：点指标 → 指标详情；返回。
- 状态：loading / success / 无适用指标 / error。
- 接口：`GET /regions/{id}/profile?period=2025`、`GET /data-values?region_id=&period=2025`。
- 验收：文本不截断到不可读；数值单位正确；空值不显示 0。

### P-M04 指标详情

- 端：移动
- 优先级：P0
- 目的：看一个指标在某区域的值、来源、图表。
- 入口：区域详情/首页指标卡。
- 主要内容：
  - 指标名/单位/年份/口径说明。
  - 数值（或“暂无数据”）。
  - 来源（数据导入/手工/接口）。
  - 图表（柱/条/饼/折线，按数据形态）。
  - 同指标多区域对比（P1）。
- 主要动作：切换年份（如有）；切换图表/表格；对比（P1）。
- 状态：loading / 有值 / 无数据 / 图表失败降级表格 / error。
- 接口：`GET /data-values?region_id=&indicator_id=&period=`、`GET /data-values/compare`、`GET /data-values/rank`。
- 验收：数值与数据库一致；单位/年份显示；空值不画 0。

### P-M05 AI 问答

- 端：移动
- 优先级：P0
- 目的：用自然语言查数据、出图。
- 入口：首页/底部导航。
- 主要内容：
  - 消息列表（用户/助手）。
  - 助手消息：结论、数据表/图表、引用、追问建议。
  - 输入框/快捷问题。
- 主要动作：提问；重试；追问；查看引用；反馈（P1）。
- 状态：idle / submitting / thinking / tool_calling / composing / done / refused / error。
- 接口：`POST /ai/chat`、`GET /ai/sessions/{id}/messages`。
- 验收：答案数字可核对；无数据明确说明；图表可渲染；超时可重试；不暴露 Key/系统提示。

### P-M06 会话列表（P1）

- 目的：查看历史问答。
- 接口：`GET /ai/sessions`。
- 验收：按时间倒序；可删除（P1）。

### P-M07 我的/帮助（P1）

- 目的：登录/身份、关于、帮助、反馈。
- 验收：不收集无关个人信息；有维护联系电话/说明（粤政易友好页要求）。

## 3. 后台

### P-A01 登录

- 目的：管理员进入后台。
- 内容：用户名/密码；错误提示；loading。
- 接口：`POST /auth/login`、`GET /auth/me`。
- 验收：未登录访问受保护页跳登录；401 处理；密码错误不泄露账号是否存在。

### P-A02 总览

- 目的：看数据覆盖率、最近导入、问答量、异常。
- 内容：指标卡；最近导入列表；覆盖率（区域×指标）；快捷入口。
- 接口：`GET /admin/dashboard`（P0 可用多个现有接口拼）。
- 验收：数字与数据库一致；空数据有提示。

### P-A03 数据列表

- 目的：查找/筛选/编辑数据值。
- 内容：筛选（区域层级/区域/指标/年份/状态）；表格；分页；编辑入口。
- 接口：`GET /admin/data-values`。
- 验收：筛选组合正确；分页；空结果提示；编辑后列表刷新。

### P-A04 数据编辑

- 目的：修订单条数据。
- 内容：区域/指标/年份只读；值输入（数值/文本）；单位提示；保存/取消。
- 动作：保存前校验；保存后审计；冲突提示（P1）。
- 接口：`PATCH /admin/data-values/{id}`。
- 验收：类型/单位校验；空值允许；保存后审计日志有 before/after。

### P-A05 导入

- 目的：上传 Excel、查看校验结果。
- 内容：模板下载；文件选择；模式（atomic/partial）；上传；进度；结果统计；错误表格/下载。
- 接口：`POST /admin/imports`、`GET /admin/imports/{id}`、`GET /admin/imports/{id}/errors`。
- 验收：原始模板可上传；错误行可定位；失败不产生脏数据（atomic）；重复导入更新。

### P-A06 导入记录

- 目的：查看历史导入。
- 内容：文件名/时间/操作人/状态/成功/失败/错误下载。
- 接口：`GET /admin/imports`。
- 验收：状态准确；错误报告可下载。

### P-A07 审计日志

- 目的：追溯谁改了什么。
- 内容：时间/用户/动作/资源/详情；筛选。
- 接口：`GET /admin/audit-logs`。
- 验收：写操作都有记录；敏感字段脱敏。

### P-A08 用户/权限（P1）

- 目的：管理六类身份（游客/申请者/查看者/编辑者/管理员/审批者）。
- 验收：不能删除最后一个 admin；禁用用户不能登录。

### P-A09 问答记录（P1）

- 目的：看用户问了什么、AI 答得如何。
- 内容：问题/答案摘要/工具调用/耗时/反馈。
- 验收：不展示密钥/系统提示；可标记问题。

## 4. 通用验收

- [ ] 所有页面有 loading/empty/error。
- [ ] 所有列表有分页/空状态。
- [ ] 所有表单有校验/错误提示/保存反馈。
- [ ] 所有数值有单位/年份/来源。
- [ ] 所有图表可降级为表格。
- [ ] 移动端 375px 宽可用；后台 1366px 可用。
- [ ] 无权限页面有友好提示（粤政易要求）。
- [ ] 不出现“undefined/null/NaN”。
