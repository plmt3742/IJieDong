## 6. 导入规则（与 05 架构一致）

> 三种来源（Excel/接口/手工）共用同一套区域/指标/单位/类型/唯一键校验；接口只负责取数/映射，手工只走单条表单。

1. **文件**：`.xls`/`.xlsx`；≤10MB；≤5000 行；表头必须匹配。
2. **区域**：
   - 区：`区域类型=揭东区`，名称=揭东区。
   - 镇街：`区域类型=镇街`，名称精确匹配 15 个；支持别名（玉窖→玉滘）。
   - 村居：`区域类型=村居`，按第一个 `-` 拆父级；父级必须存在；村名精确匹配。
3. **指标**：按 `数据名称` 精确匹配；单位必须与指标单位一致；指标必须适用于该层级。
4. **值**：
   - `number`：允许千分位逗号；必须是数字；空值 → `EMPTY_VALUE` 警告。
   - `text`：按长度限制；空值 → 警告。
5. **重复**：同一文件内 `(区域, 指标, 数据期)` 重复 → 错误。
6. **写库**：默认 `atomic`；全部通过才写；`partial` 可选。
7. **更新**：按唯一键 upsert；保留 `updated_by/updated_at`；写审计。
8. **报告**：行号、列、错误码、可读信息、建议。

### 6.1 错误码（建议）

| code | 含义 |
|---|---|
| `HEADER_MISSING` | 缺列/表头不匹配 |
| `REGION_NOT_FOUND` | 区域不存在 |
| `REGION_PARENT_NOT_FOUND` | 村居父级不存在 |
| `INDICATOR_NOT_FOUND` | 指标不存在 |
| `INDICATOR_NOT_APPLICABLE` | 指标不适用于该层级 |
| `UNIT_MISMATCH` | 单位不匹配 |
| `VALUE_TYPE_INVALID` | 数值/文本类型错误 |
| `TEXT_TOO_LONG` | 文本超长 |
| `DUPLICATE_ROW` | 文件内重复 |
| `EMPTY_VALUE` | 空值（警告） |
| `PERIOD_INVALID` | 年份格式错误 |
