# 16 · 开发必要支出评估

> 说明：以下为**量级估算**，不是报价；价格为 2026-11 常见区间，实际以云厂商/服务商/政数部门当期报价为准。金额单位：人民币。
> 分两类：**现金支出**（真正要花的钱）与**人力等价成本**（自己开发的时间价值，不是现金）。
> **详细来源与采购案例见 [19-cost-research.md](19-cost-research.md)**；本文件是速查版，冲突时以 19 为准。

## 1. 11.12 初步 Demo 现金支出

| 等保测评（二级） | 10,000–43,000 元/次 | 政府小系统常见 2–3 万；省级上限 4.3–5 万；整改另计 |

| 密评（系统评估） | 60,000–120,000 元 | 二级 6–8 万、三级 8–12 万；旧版 3–10 万偏低 |
| 密评（方案评估） | 15,000–20,000 元 | 如需要；建设前做 |
| 安全测评/渗透测试 | 10,000–30,000 元 | 小 Web/小程序；报告盖章/复测另议 |
| 上线前风险评估（广东政务云） | 13,000–20,000 元/系统 | 如强制；按框架合同量级 |
| 功能测试报告 | 0–20,000 元 | 开发商自测/第三方盖章 |
| **合计（二级，不含密评）** | **约 4.5–12 万元** | 不含整改、硬件、人力 |

> 这些费用通常由需求方/政数部门承担或申请；开发侧负责配合整改/材料。不要把它们算进“开发报价”而不说明。
> **整改另计**：等保 0–10 万（二级）/5–30 万+（三级）；密评 3–20 万+；信创迁移 0–50 万+。

## 5. 成本优化建议

1. **复用政府现有资源**：云服务器、域名、SSL、小程序主体、短信通道；先问政数部门。
2. **11.12 用 SQLite + 本地进程**：不买数据库/不装 Docker；演示足够。
3. **LLM 先用 DeepSeek API**：按量付费；设置每日限额、缓存、最大上下文。
4. **生产再上 PostgreSQL/Docker**：按实际并发/数据量扩容，不提前堆资源。
5. **私有化先评估**：没有 GPU/运维团队时，不要为了“看起来安全”上私有化。
6. **合规费用单列**：等保/信创/密评是外部测评费，不是开发费；提前让需求方立项。
7. **避免重复建设**：若粤治慧已有数据/图表能力，优先对接（需评估）。

## 7. 需要向需求方确认的费用问题

1. 是否有现成的云服务器/域名/SSL/小程序主体可以复用？
2. 等保/信创/密评的预算和承担方是谁？
3. LLM 是用公有云按量付费，还是申请政务云/私有化资源？
4. 是否需要第三方功能/安全测试报告？谁出费用？
5. 11.12 demo 是否需要公网访问？如果需要，服务器/域名谁提供？
