## 2. Demo 范围

### 2.1 必须做（Must）

1. **数据**：导入原始 Excel 模板（或演示数据），落到 SQLite；至少有区 + 15 镇街 + 15 指标。
2. **小程序（原生）**：
   - 首页：揭东区核心指标卡 + 镇街入口。
   - 区域列表/详情：区 → 镇街；村居可先列表。
   - 指标详情：数值 + 单位 + 年份 + 柱状图/表格。
   - AI 问答：输入问题 → 答案 + 数据表/图表 + 引用。
3. **后台（最小）**：登录 + 数据列表 + 导入页（或先用脚本导入，后台只读）。
4. **AI**：DeepSeek API + 3–5 个工具（区域/指标/查询/排名/图表）。
5. **文档/成本**：更新 + 可评审。

### 2.2 应该做（Should）

- 区域对比/排名（一个接口 + 一个图表）。
- 导入错误报告。
- 演示数据标注。
- 简单的 loading/empty/error。
- 后台数据编辑（单条）。

### 2.3 不做（Won't）

- 粤政易 SSO/工作台接入（等程序完成后再接）。
- 地图/GeoJSON、大屏、导出、多年趋势。
- 完整 RBAC/审核/多用户。
- Docker/生产部署（本地跑；Docker 后置）。
- 完整测试/压测/等保/信创。
- 微信正式 AppID/备案（用测试号/开发者工具；如需真机预览再申请）。

## 3. Demo 脚本（3–5 分钟）

```text
1. 打开后台/命令行，导入 Excel（或展示已导入数据）。
2. 打开微信开发者工具，进入小程序首页：
   - 看到揭东区核心指标。
3. 点“镇街” → 选“曲溪街道” → 看区域详情。
4. 点“常住人口” → 看数值 + 柱状图/表格。
5. 打开 AI 问答，问：
   “2025 年揭东区各镇街地区生产总值排名前 5 是哪些？”
   → 答案 + 条形图 + 引用。
6. 追问：“换成常住人口呢？” → 答案 + 图表。
7. 展示后台导入记录/数据列表（可选）。
```

## 7. 砍范围顺序（如果延期）

按以下顺序砍，保住主路径：

1. 后台数据编辑 → 只保留列表/导入。
2. 区域对比/排名 → 只保留单指标图表。
3. AI 图表 → 只保留答案 + 表格。
4. 村居层级 → 先区/镇街。
5. 导入 UI → 命令行/脚本导入。
6. 图表类型 → 只保留柱状图 + 表格。
7. 后台登录 → 本地固定 token（仅 demo，标注不安全）。

**不能砍**：数据导入、区域浏览、指标详情、一个可用的 AI 问答、文档/成本。
