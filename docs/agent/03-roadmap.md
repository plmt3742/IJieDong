# 03 · 路线图与进度

## 1. 原则

1. **先数据后界面**：没有可靠的数据底座，图表和 AI 都是演示泡沫。
2. **先闭环后完整**：先跑通“导入 → 浏览 → 图表 → 问答”，再补权限、导出、地图、粤政易。
3. **先契约后代码**：API/数据模型/目录先定，再并行实现。
4. **合规后置但不忽视**：MVP 不阻塞于等保/信创，但架构预留政务外网、ARM64、私有化 LLM。
5. **每批次可验收**：不设“做了两周但看不出东西”的批次。

## 5. 关键路径

```text
11.12 demo（B-002）：
数据模型 + SQLite + 导入/种子
   ↓
查询 API
   ↓
原生小程序浏览 ──→ 图表（ChartSpec）──→ AI 问答（DeepSeek）
   ↓
最小后台（登录/列表/导入）
   ↓
演示 + 技术文档 + 成本评估

11.12 之后（B-003~B-006）：
数据治理/后台 → 可视化/AI 完善 → 稳定/部署 → 粤政易/合规
```

**不能并行跳过的**：数据模型与导入。**可以并行的**：后台与小程序（契约确定后）；图表与 AI（ChartSpec/API 确定后）。
