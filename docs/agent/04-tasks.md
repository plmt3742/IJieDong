# 04 · 任务清单

## 0. 使用规则

- 任务状态以本文件为准；批次记录只写“做了什么”，不替代任务状态。
- 领取任务时改成 `DOING`；完成改成 `DONE`；被外部条件卡住改成 `BLOCKED` 并写原因。
- 新任务必须写清：**ID、优先级、依赖、验收标准、估算**。没有验收标准不允许进 P0。
- 优先级：`P0` 最小闭环必须；`P1` 有余力就做；`P2` 明确不做/未来。
- 一个任务尽量 ≤ 3 天；超过就拆。
- 任务 ID 前缀：`DOC` 文档、`DATA` 数据、`BE` 后端、`FE` 后台、`MP` 小程序、`AI` 智能体、`OPS` 部署、`QA` 测试、`YX` 粤政易、`SH` 跨模块。

### 任务模板

```text
ID:
标题:
优先级:
依赖:
估算:
验收标准:
委派: 主 agent / subagent（工作包 ID）
验收: 主 agent 复跑命令/手动路径
状态: TODO | DOING | DONE | BLOCKED | DEFERRED
备注:
```
